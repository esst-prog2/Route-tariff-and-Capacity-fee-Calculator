# Agent instructions

## Planning log

Keep a planning log in `PLANNING_LOG.md` at the repository root. Every time a decision about the project is made — a requirement, a number, a name, a tool, a scope change — append one line to the log at that moment, not at the end of the task or session. Each line gives the date, what was decided, and who decided it (the user or the agent; if the agent proposed it and the user agreed, say so). Never rewrite, reorder, or delete earlier lines; if a decision changes, append a new line that says which earlier decision it supersedes.
